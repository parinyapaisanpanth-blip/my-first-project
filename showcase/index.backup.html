05 — Design principles
กฎที่ทุก agent ยึดถือ
เพื่อให้ brief ใช้งานได้จริง ไม่ใช่แค่อ่านดูดี
Source-first
ทุก bullet ใน brief ต้อง trace กลับไปหา source file ได้ ห้ามแต่งตัวเลขจากความจำ
Context isolated
mint อ่านแค่ 10-K, arm อ่านแค่ call transcript — ไม่มี agent ข้ามอ่าน source ของกัน
Honest > Confident
ถ้าข้อมูลไม่พอ ระบุตรงๆ ว่า "ไม่มี source" ดีกว่า hallucinate ตัวเลขสวยหรู
Thesis ไม่ใช่ religion
frame track delta ทุก brief + kill conditions ป้องกันไม่ให้ commitment bias กัด portfolio
ไม่มี buy/sell rec
ระบบนี้ทำ research summary เท่านั้น decision ยังเป็นของคุณ 100%
Token aware
knowledge/ เก็บข้อมูลถาวรลด WebSearch ซ้ำ — Haiku สำหรับงาน simple, Sonnet สำหรับ synthesis

สร้างด้วย Claude Code · ข้อมูลทั้งหมดเป็น research summary ไม่ใช่คำแนะนำซื้อขาย
